INF 321 - PROJETO E DESENVOLVIMENTO DE SISTEMAS PARA A WEB

Prof. Lucas Francisco da Matta Vegi

Objetivos: Introduzir ao aluno conceitos arquiteturais básicos da Web, focando em aspectos de projeto e implementação de sistemas e softwares para a mesma; Treinar o desenvolvimento de aplicações cliente-servidor e de sistemas com comunicação por troca de mensagens; Treinar o desenvolvimento de aplicações multiplataforma; Introduzir o aluno à linguagens de marcação e de folhas de estilo; Prover contato inicial do estudante com tecnologias de desenvolvimento backend; Introduzir, por meio de aplicações Web, conceitos de comunicação assíncrona cliente-servidor e acesso a bancos de dados no servidor.

O que você irá aprender:

  • Introdução à Web
  • Linguagens para Desenvolvimento frontend
  • Linguagens e Frameworks para Desenvolvimento backend
  • ntrodução à Middleware
  • Tópicos Avançados em Web
